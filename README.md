# Study Group Motion Week 6

Topic : API

API atau Application Programming Interface adalah jembatan dari aplikasi frontend ke aplikasi backend, tujuan dari API tersendiri adalah menyambungkan kedua aplikasi tersebut.
API sangat dibutuhkan apabila bekerja dalam bentuk tim dimana terdiri dari frontend dan backend.

API menggunakan sistem CRUD yaitu
- Create (POST)
- Read (GET)
- Update (PUT)
- Delete (DELETE)
